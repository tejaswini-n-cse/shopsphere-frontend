# ShopSphere – Online Shopping Frontend

A clean, responsive, single-page e-commerce website built with vanilla HTML5, CSS3, and JavaScript.

![QR code generator screenshot](screenshot.png)

## Features
- **Product Catalog Grid**: Display items with categories and pricing.
- **Search & Filter**: Live product search bar and category filtering.
- **Sorting**: Sort products by price (low to high, high to low).
- **Interactive Cart Drawer**: Side drawer to view selected products, adjust quantities, and calculate real-time totals.
- **Responsive Layout**: Optimized for mobile, tablet, and desktop views.

## How to Run
1. Open `index.html` directly in any standard browser.
